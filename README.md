## 📋 Описание

Memory Game — это интерактивное веб-приложение, созданное с использованием React. Цель игры — открыть все пары карточек за наименьшее количество ходов. Каждая карточка скрывает изображение, и игрок должен запомнить расположение карточек, чтобы находить совпадения.

### ✨ Особенности

- **Интерактивный геймплей:** Кликайте по карточкам, чтобы открыть их и найти пары.
- **3D-эффект переворота:** Красивая анимация переворота карточек при открытии.
- **Отслеживание ходов:** Счетчик ходов показывает, сколько попыток вы затратили.
- **Экран победы:** После открытия всех карточек появляется специальное окно с поздравлением и количеством ходов.
- **Перезапуск игры:** Возможность начать новую игру прямо из окна победы.
- **Адаптивный дизайн:** Игра корректно отображается на различных устройствах, включая мобильные телефоны (размеры 320px, 375px, 425px и другие).
- **Легкий вес и производительность:** Приложение оптимизировано для быстрой загрузки и плавной работы.

## 🎮 Как играть

1.  Нажмите на любую карточку, чтобы открыть её.
2.  Нажмите на вторую карточку. Если изображения совпадают, пара остается открытой.
3.  Если изображения не совпадают, обе карточки снова закроются.
4.  Повторяйте, пока не откроете все пары.
5.  По завершении игры вы увидите окно с поздравлением и общим количеством ходов.
6.  Нажмите "Играть снова", чтобы начать заново.

## 🚀 Запуск локально

Чтобы запустить приложение на вашем компьютере, выполните следующие шаги:

1.  Убедитесь, что у вас установлен [Node.js](https://nodejs.org/).
2.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/Uri4-78/Memory-Game.git
    ```
3.  Перейдите в папку проекта:
    ```bash
    cd Memory-Game
    ```
4.  Установите зависимости:
    ```bash
    npm install
    ```
5.  Запустите приложение в режиме разработки:
    ```bash
    npm start
    ```
6.  Откройте [http://localhost:3000](http://localhost:3000) в вашем браузере.
